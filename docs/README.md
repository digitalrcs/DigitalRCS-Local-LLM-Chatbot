## A few useful words

| Word | Meaning |
| --- | --- |
| Bridge | The PC program that helps Franky listen, get an answer, and speak |
| Model | The downloaded AI that writes answers, or a smaller AI used for hearing and speech |
| LM Studio | A separate app that runs a chat model on your computer |
| Firmware | The software inside the robot |
| USB flashing | Installing new firmware through a USB data cable |
| API key | A private key that lets a program use your online account; keep it secret |
| Server | A computer or program that waits for requests from other devices |
| Port | The number after the colon in an address; Franky's bridge uses `8766` |
| Local | Running on your computer or home network |
